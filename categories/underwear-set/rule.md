## 三、识别安全规则

- 根据文件扩展名 + **末尾连字符数字**匹配，例如 `-1.png`，不从货号中的数字猜测编号。
- 无编号的 **上衣背面** 与 **裤子背面** 单凭文件名无法区分。程序必须留空并产生待人工确认映射文件，不得按字母/文件名排序猜测。
- 无编号 JPG 可被认作“其他细节”，但多张时属于冲突，等待确认。
- 同字段多张、尺寸不符、无有效图片：记录警告，不静默挑选第一张。
- 图片尺寸是校验标准；不缩放或覆盖原图。
- 输出字段为 `货号`、`颜色` 与 `@上衣正面` 等图片字段；所有图片字段名均带 `@`。
- 本文只定义数据槽位顺序，不定义 InDesign 拼图位置；实际版式由用户的 ID 模板决定。
